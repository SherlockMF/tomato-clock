# 平行人生 · 旅居番茄钟

第一季《南下十五日》共 45 段。旅人辞了北京的工作，坐车去武汉看老同学阿宁。前同事唐青发来的照片里，采访还在，名字却被旅人亲手删掉了。旅人在开往武汉的火车上重新翻开速写簿。到了长沙，可以选和夜市摊主互画，或一个人留下来看整条街点灯。

首页可以直接选 25 或 50 分钟并开始专注。首次使用会弹出旅人设置，填好昵称和人格后，可以开始倒计时，也可以先读免费序章。每个虚拟日有早、午、晚三段。专注 25 分钟解锁一段，50 分钟解锁两段。中途遇到抉择，剩余的一段会留到选完以后。读完整季需要 18 小时 45 分钟真实专注。试读版另有跳过计时的入口。

读者可在现代浏览器直接打开[第一季正式版](南下十五日/index.html)。这个 HTML 内含全部正文、分支和插画，可单独转发，或作为静态网站的首页。想快速校稿请打开[编辑试读版](第一季·南下十五日试读.html)。两个版本分别保存进度。手机浏览器可以生成 1080 × 1440 的 PNG，长按保存，另可复制完整手记。

## 运行

开发服务需要 Node.js 24.15.0 或更高版本。在本目录运行 `node scripts/studio.ts --port 4318`，打开[第一季正式版](http://localhost:4318/season1)或[可跳过的单文件试读](http://localhost:4318/season1-preview)。源代码编辑入口是 `/season1-editor?preview=1`，年度版在 `/annual`。进度保存在当前浏览器，同一网址和端口可以接着读。再次打开新版时，已有的旧旅程会在页底出现续读入口，通往[旧版存档](南下十五日/旧版存档/)。离线续旧档时需保留这份目录，新读者只需一份 HTML。

## 开发与核验

全季有 11 处由读者决定。第 5、22 段影响 T/F，第 10、40 段影响 S/N，第 14、26 段影响 I/E，第 18、32 段影响 J/P，每次 5 分。第 34 段订床、第 43 段合照或递号码、第 44 段买票只记录剧情和实际收支。新旅人从 57/43 出发，另有 15 次日常反应。列车上的纸袋怎么交接、散戏后怎么陪陈渡，由旅人参照当时的性格和所选偏好决定。读者可在序章、第 1 段或档案里选做法，留下自己的备注。偏好用上时，手记下方有记录，可点进档案回看。展开「上回读到哪儿」可以回顾已读的情节和最近见过的人。

旅人有 2,600 元可用旅费。长沙五晚床位共 350 元。摆摊卖出 90 元，错券的 150 元补送费由露露先垫，旅人可分担 75 元或一起换盒。阳朔普通床四晚 280 元，扣除余下餐费还能留够 238 元北上硬座才可选。如果住原床会凑不齐西去的 520 元，旅人会问到四晚 130 元的后院通铺。换宿付首晚 70 元，后三晚包住，值两个早班，每班结束挣 60 元。订床时可预看各自的余额。旧存档照已读到的报价结算。

专注结束后，每段正文以对应场景的插图开篇。旅途手记按日期连读，每章都有标题、时段和地点。50 分钟解锁的两章各有分享入口，收支与人格转变各自归到发生的那一章。行李箱里的纪念可以点回原文。去贵阳的旅人还会收好画着三口蒸锅的早点地图。

在已安装开发依赖和 Python Pillow 的环境运行 `node scripts/pack-season1.mjs`，可压缩本季实际用到的插图，生成两份独立网页和[三批连续样稿](南下十五日分批试读/)。运行 `python tools/season1-browser-smoke.py http://localhost:4318/season1` 可核验桌面与手机尺寸、完整离线试读、前情与偏好溯源、旧档和跨标签计时。额外传入 `--realtime` 会实际等待 25 分钟完成一次专注。

- `studio/` 存放页面、计时状态和分享图素材；`src/travel-story/` 存放年度故事与偏好逻辑。
- [年度读本](reports/roaming-year/beijing-365d-revised/年度旅居试读.html) 是默认正文和收支的运行数据。
- [16 条年度旅途手记](平行人生·16条年度旅途手记.html) 可单独在浏览器中打开。
- 安装开发依赖后运行 `npm run check`，执行类型检查、lint、测试及编译。
- 浏览器回归可用 `python tools/annual-browser-smoke.py http://localhost:4317/annual`，需要本机安装 Python Playwright 和 Chrome。

本季新画了校样、蒸糕小院、长沙印店、阳朔渡口和旧票袋。可查看网页实际导出的[武汉米糕](南下十五日分批试读/分享样图-武汉米糕.png)、[长沙印店](南下十五日分批试读/分享样图-长沙印店.png)和[阳朔票袋](南下十五日分批试读/分享样图-阳朔票袋.png)。
