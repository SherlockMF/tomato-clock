# M3.3 人物属性与持续旅途

2026-11-18。M3.3 是 M3.2 第三轮上的可选自主模拟模式。主角与两名具名 NPC 在廊坊、蓝渡镇和青岑镇生活。站点、交通、费用及水情均为合成数据。

## 打开并接续

在项目目录执行 `npm run studio -- --port 4333`，打开[本地旅途实验台](http://127.0.0.1:4333/life32r3?mode=journey)。可以打开「阿远的三地旅程」，也可以按定居、旅行、创作或低资产背景创建自己的实验。每次推进会保存人物、行囊、在途行动和未完成的事务。点击属性变化旁的事实编号可回看原因。

## 什么会影响下一次选择

- 四项属性分开记录。体能和实务能力缓慢变化，同类实践的边际收益递减。探索意愿与相处意愿随近期经历起伏。每次变化记录当事人、行动、前值、后值和来源。同一机会的中间片段不会反复获得成长。
- 每本馆藏书都有归属、现处地或携带人、磨损和借阅情况。异地归还后可以被人领走，交回本馆后再借出或进入修补。水尺复测会改变哪些站点接收异地还书。遇到高水或低水时，感兴趣者还可能现场取材，完成的手记可被写成作品并被其他人实际阅读。
- 资金、营业时间、交通、疲劳和食宿约束继续参与选择。三站之间有实际耗时的步行路段，部分有收费公交。两座外镇的书站可就地洗护、补给和过夜。现金吃紧时人物会预留能实际到达的床位。旅途无末章，机会可以再次形成。书、地点和行动题材仍是有限的。

## 两段能核对的体验

在创作背景、种子 19 的轨迹里，知夏第 29 天在青岑记录退水留下的泥纹，第 30 天完成作品，第 32 天阿林在当地读到这份作品并提出问题。事实和机会引用逐项连得起来。同一条轨迹第 144 窗只有一顿 6 元的饭和去旧街区的十分钟步行。[连续四窗和作品来源](知夏的连续四窗.md)

30 天 SQLite 样本有 106 次跨区到达。37 段中间停留没有推进当地事务，其中 3 次随即返回来处。数字包括换乘，以及途中只有进餐、等待等日常行为的停留。年度低资产样本有 40.37% 的清醒时间用于等待。在 141,460 分钟的等待中，128,000 分钟对应有候选但每项都带有即时或行程限制的决策，7,305 分钟对应没有候选。远途往返和类似的馆藏交接仍会重复。真人是否想读下一窗仍待验收。

## 存档与兼容性

创作背景、种子 19 的 30 天独立 SQLite 验证采用每天四次 25 分钟和一次 20 分钟专注，倍率 1:8。累计 150 窗，每天重开数据库，另在结束后重开做完整核验，重复提交最后一窗共 30 次。每次恢复的状态摘要一致，逐窗重放、三人的 M1 时间与资金审计、因果引用检查通过。30 天结束时累计清醒 28,800 分钟，状态摘要为 `fbd6eb8aadda2051880139df9b1dc6a550da141ee1c31bd0ffe575c144fc47f8`。

免费住宿触发了早期短窗测试漏掉的存档问题。M1 对零分收费取负后在内存里产生 `-0`，SQLite 的 JSON 还原为 `0`。旅途公开快照现在统一零分的表示，定向回归覆盖免费住宿后严格重放。原 M3.2 第三轮的八条七天配置也已逐条对照冻结的事件与状态摘要。

全年轨迹使用分批内存推进。30 天是此次用真实 SQLite 验证的长度。长期存档会累积逐分钟记录和逐窗快照，尚未做一年数据库负载或真人阅读验收。

最终引擎摘要为 `life32r3-b96203c209b237cf`。`npm run check` 完成类型检查、lint、268 项测试及构建。`npm run test:boundaries` 的 35 项边界测试通过。Studio 测试覆盖原存档接续与未知版本拒绝，本地示例已实际重启服务并接续第三窗。
