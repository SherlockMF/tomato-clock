# 持续旅途的等待对照

每个角色用同一背景、同一种子各跑两遍。两版每个模拟日均推进 960 分钟清醒时间，睡眠照常跨过日历。旧版十条轨迹的已有指标已与上次保存的结果逐项核对。

| 样本 | 清醒时间中等待，旧 → 新 | 清醒时间中连续等满两小时的部分，旧 → 新 | 通勤，旧 → 新 |
|---|---:|---:|---:|
| 4 种背景 × 2 个种子，30 天 | 24.3% → 16.6% | 12.5% → 4.2% | 21.9% → 21.0% |
| 知夏，种子 19，100 天 | 31.0% → 21.8% | 20.0% → 7.9% | 22.6% → 18.8% |
| 小周，种子 41，365 天 | 40.4% → 21.0% | 28.8% → 10.8% | 20.7% → 20.4% |

长等指一段连续等待达到 120 分钟，该段全部分钟均计入。睡眠、进餐、移动或其他行动会中断连续等待。

## 专注窗口

月度样本共 1,152 个完整窗口，每个窗口对应 25 分钟专注、8 倍速。整窗都在等的次数从 15 降至 0。没有完成带后果事务的窗口从 91 降至 17。这里用带语义标记的实际进展计数，已发工资的班次也算一次。读者是否觉得有趣仍需试读。

新月度样本在家时间占 4.4%，学习占 0.6%。其中最长的一次连续等待为 240 分钟。

## 已落到引擎的变化

- 书站柜台与住宿区采用各自的活动时间。睡前能装下的 15 分钟联系可以执行。长等后，人物会重新考虑附近评分较低但可行的安排。生理、住宿、经费和约定仍参与校验。
- 河岸涨水带来有上限的漂枝。堆积会影响还书点选择，实际清理才会减量。实地观察须有已知站点和可观察水况。重访相同水位带需要中间见过相反水况，并与上次同类观察至少相隔两天。
- 久坐者可以把一项未开工的远处锻炼改为当地拉伸。同地朋友可以分享已发生的旅途经历。异地通信只在实际等待后尝试，同一消息只有实际回复才影响信任。
- 新旅途采用书站公共服务委托的经济设定。书站先垫付值班或维修工资，月初从外部委托方收回上月已付的工时款。没有完成服务就没有回款。个人账本只在实际工作时记工资。旧旅途按原配置重放。

## 文件与复现

- 人物与世界规则位于 `src/journey/{world,world-types,attributes,correspondence}.ts`。
- 候选、地点、排程与结算位于 `src/life32r3/{city,planner,itinerary,engine,state,types}.ts`。
- Studio 预设和历史版本接续位于 `src/studio/{life32r3-catalog,life32r3-routes}.ts`。
- 对照脚本位于 `scripts/journey-eval.ts`。回归测试位于 `tests/journey-runtime.test.ts`、`tests/journey-world.test.ts`、`tests/studio/journey.test.ts`。

```powershell
node scripts/journey-eval.ts 30 19
node scripts/journey-eval.ts 30 41
node scripts/journey-eval.ts 100 19 creator
node scripts/journey-eval.ts 365 41 low_assets
```

任一命令末尾追加 `--legacy` 可重放旧规则。`npm run check` 通过，含 286 项测试。`npm run test:boundaries` 通过 35 项。逐样本分钟数、活动分布及末周任务见[对照数据](local-activities.json)。
